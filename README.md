# Sales Dashboard (Power BI)

## About Project

This is an interactive **Sales Dashboard** created using Power BI. It helps analyze sales performance, profit, and customer insights in a simple and visual way.

## Features

* Total Sales, Profit & Orders KPI
* Monthly Sales Trend (Line Chart)
* Category & Sub-category Analysis
* Top 10 Customers & Products
* Region / City-wise Sales (Map)
* Interactive Filters (Slicers)

## Dataset

The dataset contains:

* Order Date
* Customer Name
* Product Category
* Sales, Quantity, Profit
* Region / City

## Tools Used

* Power BI

## Key Insights

* Top products generate maximum revenue
* Certain regions perform better than others
* Sales increase during specific months

## How to Use

1. Download `.pbix` file
2. Open in Power BI Desktop
3. Use filters to explore data
